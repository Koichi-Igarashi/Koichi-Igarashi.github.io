# Papers

PDF files published on the website (e.g. accepted manuscripts that the
publisher allows you to share). Reference them from `data/publications.yml`:

```yaml
    pdf:
      - url: "papers/Journal_Igarashi_2027.pdf"
        label: "Accepted manuscript"
```

PDFs do not have to be stored here: `url` can also point to an institutional
repository (e.g. HUSCAP), the publisher, or ResearchGate. The first PDF gets
the PDF icon in the publication list; further ones are listed under the
citation. Files in this folder are published only once (at the site root) and
the English page links to the same file.
